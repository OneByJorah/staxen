staxen

Production-ready Docker Compose stack for AI agents — one command, self-hosted, privacy-first.

View on GitHub Quick Start

Features

Everything you need to run AI agents on your own hardware.

🚀

One Command Deploy

docker compose up -d and your entire AI agent stack is ready.

🔒

Privacy-Focused

All data stays on your infrastructure. No third-party APIs, no data leaks.

💻

CPU-Only

No GPU required. Runs on any machine — VPS, homelab, or bare metal.

🧠

Local LLMs

Ollama-powered language models (Llama, Mistral, and more) run entirely on your machine.

🔎

Private Search

SearXNG provides privacy-respecting web search without tracking or profiling.

🧩

Vectored Memory

Qdrant vector database + Honcho long-term memory for persistent agent state.

📝

Obsidian Sync

CouchDB-backed Obsidian LiveSync for notes, knowledge, and agent memory vaults.

⚙️

Web Automation

Selenium standalone Chrome for browser automation tasks.

Quick Start

Get the full stack running in under a minute.

# Clone the repo
$ git clone https://github.com/OneByJorah/staxen.git
$ cd staxen

# Copy environment template
$ cp .env.example .env

# Deploy the entire stack
$ docker compose up -d

# Check service health
$ ./scripts/healthcheck.sh
